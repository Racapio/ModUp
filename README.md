# ModUp — обновление модов Minecraft

**Скачать:** [последняя версия ModUp.exe](https://github.com/Racapio/ModUp/releases/latest). Дальше ModUp обновляется сам: при запуске проверяет релизы и предлагает обновиться.


Одно окно: выбираешь папки с модами (или находишь инстансы Prism / MultiMC), ModUp сверяет каждый jar
с **Modrinth** (по отпечатку файла — узнаёт даже скачанные руками) и **GitHub Releases** (ссылка из
самого мода, список известных или указанная тобой) и показывает, что можно обновить.

- Галочки: обновить выбранные, только один мод, мод **во всех папках сразу** или **всё везде**.
- Подбирает файл под версию игры и загрузчик папки (26.1.2 и 26.2 не перепутает).
- Перед заменой старые jar уходят в `modup-backup` рядом с папкой `mods`; «Откат» возвращает последнее обновление.
- Показывает проблемы папки: дубли модов, повторно скачанные файлы `(1)`, мод под другую версию игры.
- Мод без источника — один раз вставь ссылку на его GitHub. «Пропустить версию», «Больше не проверять».
- **«На другую версию»**: подбирает каждый мод папки под другую версию игры (например 26.1.2 → 26.2) — с Modrinth,
  а если там ещё нет — с GitHub; докачивает новые обязательные зависимости и скачивает всё в выбранную папку
  инстанса новой версии. Исходная папка не меняется; что лежало в новой — уходит в бэкап («Откат» вернёт).
- Игра запущена — обновлять можно: она доработает на старых файлах, новые подхватит после перезапуска.

## Для друзей

Скачай `ModUp.exe` и запусти — ставить ничего не нужно (нужна Windows 10/11; движок окна — встроенный Edge WebView2).
Windows может предупредить «неизвестный издатель» (exe не подписан) → «Подробнее» → «Выполнить в любом случае».
Настройки хранятся в `%APPDATA%\ModUp`.

GitHub без токена даёт 60 проверок в час; ответы кэшируются (10 мин, повторные запросы «не изменилось» в лимит
не идут). Если проверок много — в «Настройках» можно вставить свой токен GitHub (без прав, только чтение публичного).

## Разработка

```
python -m venv .venv && .venv\Scripts\python -m pip install pywebview pyinstaller
.venv\Scripts\python main.py            # окно
.venv\Scripts\python tests_modup.py     # офлайн-проверки (версии, выбор файла из релиза)
.venv\Scripts\python devserver.py       # та же страница в браузере, подключённая к ядру (для отладки UI)
.\build.ps1                             # dist\ModUp.exe
```

`modup/scan.py` — инстансы и jar, `versions.py` — версии игры и модов, `sources.py` — Modrinth/GitHub,
`engine.py` — проверка, проблемы, замена с бэкапом и откат, `api.py` — мост для окна, `ui/index.html` — окно.
`MODUP_HOME` — другая папка настроек (для тестов).

## Перенос на другую версию игры

«⇢ На другую версию» подбирает каждый мод под новую версию (Modrinth, затем GitHub) и скачивает в папку нового инстанса; исходная папка не меняется.
- Можно выбрать сам инстанс, его `.minecraft` или пустую папку — папку `mods` ModUp найдёт или создаст.
- Галочками выбирается, что перенести из старой папки игры: настройки игры (options.txt), список серверов, настройки модов (config, без кэшей вроде `repo`/`item-repo`/`backup`), ресурс-паки, шейдеры, скриншоты. То, что в новой папке уже было и отличается, уходит в бэкап; «Откат» возвращает и моды, и настройки.
- Мод, скачанный не с Modrinth (Essential с essential.gg, Sodium с CurseForge), ищется по своему id.
- После переноса в `modup-backup\<дата>eport.txt` — что перенесено и почему что-то нет.

## Издатель «неизвестен»

Строку «Издатель» в окне Windows (SmartScreen/UAC) Windows берёт только из цифровой подписи exe. Автор (Racapio) записан в сведения о файле (Свойства → Подробно), но чтобы Windows писал издателя, exe нужно подписать сертификатом подписи кода (платный OV/EV или Azure Trusted Signing). Самоподписанный сертификат на чужом ПК не поможет.

## Обновление самого ModUp

Новая версия — релиз в репозитории `Racapio/ModUp` с файлом `ModUp.exe`. ModUp при запуске спрашивает GitHub о последнем релизе; по «Обновить» скачивает exe, сверяет SHA-256 (его публикует GitHub), переименовывает себя в `ModUp.old.exe`, кладёт новый на место и перезапускается. Старый файл удаляется при следующем запуске. Если папка с ModUp.exe недоступна для записи — окно с ошибкой, текущая версия продолжает работать.

Выпуск (у автора): `python release.py 1.4.1 "что нового"` — версия, сборка, код в этот репозиторий, релиз.
